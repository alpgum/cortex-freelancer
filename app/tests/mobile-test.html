Quick-Fix CSS for Top Mobile Issues

1. Prevent Horizontal Scroll (overflow-x)

/* Add to styles.css — global mobile overflow fix */
@media (max-width: 430px) {
  html, body {
    overflow-x: hidden;
    max-width: 100vw;
  }
  .panel, .dash-grid, .form-row,
  .fee-compare, .job-list, .breakdown {
    max-width: 100%;
    overflow-x: hidden;
  }
}

2. Fix Overlapping Elements & Grid Collapse

/* Dashboard grid → single column on mobile */
@media (max-width: 430px) {
  .dash-grid {
    grid-template-columns: 1fr !important;
  }
  .dash-header {
    flex-direction: column;
    align-items: flex-start;
  }
  .form-row {
    flex-direction: column;
  }
  .score-ring-wrap {
    flex-direction: column;
    align-items: flex-start;
  }
  .fee-bar {
    flex-direction: column;
    align-items: flex-start;
    gap: 0.25rem;
  }
  .fee-bar .fee-label { width: auto; }
  .fee-bar .fee-track { width: 100%; }
}

3. Ensure Readable Text (min font-size)

/* Enforce minimum readable font sizes on mobile */
@media (max-width: 430px) {
  body { font-size: 15px; }
  .panel-title { font-size: 0.75rem; }
  .breakdown-item .label,
  .job-info .job-meta,
  .feed-time,
  .fee-tag { font-size: 0.72rem; }
  input, select, textarea,
  .btn, .btn-sm { font-size: 16px; }  /* prevents iOS zoom */
}

4. Reachable Touch Targets (min 44px)

/* WCAG 2.5.5 — minimum 44×44px touch targets */
@media (max-width: 430px) {
  .btn, .btn-sm, .btn-analyze,
  .manual-toggle, .btn-secondary,
  .job-item, a, button {
    min-height: 44px;
    min-width: 44px;
    padding: 0.6rem 1rem;
  }
  .btn-sm {
    padding: 0.5rem 0.8rem;
    font-size: 0.75rem;
  }
}

5. Tool Page Container Fix

/* Tool pages — prevent wide content from breaking layout */
@media (max-width: 430px) {
  .tool-container, .tool-content,
  main, .content-area, .tool-body {
    max-width: 100vw;
    padding-left: 0.75rem;
    padding-right: 0.75rem;
    word-break: break-word;
  }
  table {
    display: block;
    overflow-x: auto;
    -webkit-overflow-scrolling: touch;
  }
  pre, code {
    white-space: pre-wrap;
    word-break: break-all;
    max-width: 100%;
  }
}
