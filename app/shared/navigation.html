🧭 Navigation System Demo

This page demonstrates the universal navigation system for Cortex Freelancer. It includes the top navbar, breadcrumbs, command palette (⌘K), and mobile hamburger menu.

📦 Integration — Two Lines

Add this to any Cortex tool HTML file to enable the universal navigation:

<link rel="stylesheet" href="/app/shared/css/navigation.css">
<script src="/app/shared/js/nav-core.js"></script>

⚙️ Configuration (Optional)

Set window.CX_NAV before loading the script to customize behavior:

<script>
  window.CX_NAV = {
    breadcrumbs: true,  // show breadcrumb trail
    search: true,      // show search + ⌘K palette
  };
</script>
<script src="/app/shared/js/nav-core.js"></script>

🔌 JavaScript API

Control navigation programmatically via CortexNav:

// Open command palette
CortexNav.openPalette();

// Navigate to a tool by ID
CortexNav.goTo('invoice');

// Register a new tool at runtime
CortexNav.registerTool({
  id: 'my-tool', name: 'My Tool',
  icon: '🚀', href: '/app/tools/my-tool.html',
  category: 'Custom', desc: 'Custom tool'
});

// Set breadcrumbs programmatically
CortexNav.setBreadcrumbs([
  { name: 'Home', href: '/app/' },
  { name: 'My Section' }
]);

// Get currently active tool
CortexNav.getActiveTool();
