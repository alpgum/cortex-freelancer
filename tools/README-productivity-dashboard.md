# Productivity Dashboard Generator

**CFX-057b** — Interactive HTML dashboard from time tracking data.

## Features
- Weekly/monthly/quarterly productivity heatmaps
- Revenue vs hours visualization (Chart.js)
- Client profitability ranking with effective rates
- Focus time analysis (deep work %, session lengths)
- Burnout risk indicator with actionable advice
- Dark-themed responsive design
- Export to HTML, JSON, or CSV

## Usage
```bash
python productivity_dashboard.py generate --period monthly
python productivity_dashboard.py summary
python productivity_dashboard.py export --format csv
```
