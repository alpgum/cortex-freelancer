# Portfolio Site Generator

**CFX-059b** — Generate a complete responsive portfolio website.

## Features
- Professional dark-themed single-page design
- Project showcase with category filtering
- Skills visualization with animated bars
- Testimonials section
- Contact form
- SEO meta tags
- Fully responsive (mobile-first)
- JSON config for customization

## Usage
```bash
python portfolio_site_generator.py demo --output portfolio.html
python portfolio_site_generator.py generate --name "Jane Dev" --title "Full-Stack Developer"
python portfolio_site_generator.py generate --config my_portfolio.json --output site.html
```
