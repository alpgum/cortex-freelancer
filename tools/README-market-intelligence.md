# Market Intelligence Reporter

**CFX-065b** — Freelancer market research and competitive positioning.

## Features
- Rate database: 30+ skills across 6 categories, 4 experience levels
- Demand trends with YoY growth and monthly job counts
- Regional rate multipliers (12 regions including EG, PK, NG, TR)
- Competitive positioning analysis
- Market opportunity identification
- Full market intelligence reports

## Usage
```bash
python market_intelligence.py rates --skill "react" --experience senior
python market_intelligence.py trends --category web-development
python market_intelligence.py positioning --skills "React,Node.js" --rate 95 --region turkey
python market_intelligence.py opportunities --skills "React,Python"
python market_intelligence.py report --skill "full-stack" --region global
```
