# Product Hunt Assets Checklist

## Required Assets

### Logo
- [ ] Square logo — 240×240 px, PNG, no rounded corners (PH adds them)
- [ ] Ensure logo is clear and recognizable at small sizes

### Gallery Images (up to 8)
- [ ] **Image 1** — Hero screenshot showing main dashboard/landing page (1270×760 px)
- [ ] **Image 2** — Profile analysis tool in action
- [ ] **Image 3** — Fee calculator comparison view
- [ ] **Image 4** — Proposal generator output
- [ ] **Image 5** — Rate calculator results
- [ ] **Image 6** — Before/after or results showcase
- [ ] **Image 7** — Mobile responsive view (optional)
- [ ] **Image 8** — Pricing page or social proof (optional)

**Specs:** 1270×760 px recommended, PNG or GIF, max 3 MB each

### Thumbnail / OG Image
- [ ] 600×600 px thumbnail for social sharing
- [ ] Eye-catching, clear text readable at small sizes

### Video (Optional but Recommended)
- [ ] Product demo video — 1–3 minutes max
- [ ] Upload to YouTube (unlisted) and link in PH listing
- [ ] Show real usage, not marketing fluff
- [ ] No intro animations longer than 3 seconds

## Listing Copy

### Tagline (60 characters max)
- [ ] Draft tagline: "AI tools that help freelancers earn more and work smarter"
- [ ] Alternative: "Optimize your freelance rates, proposals, and platform fees"

### Description (260 characters max)
- [ ] Short description covering the core value prop
- [ ] Include 2–3 key features
- [ ] End with a call to action or differentiator

### Topics/Tags
- [ ] Freelance
- [ ] Artificial Intelligence
- [ ] Productivity
- [ ] SaaS
- [ ] Developer Tools (if applicable)

### Maker Comment
- [ ] Draft first comment (posted immediately at launch)
- [ ] Include: why you built it, key features, what feedback you want
- [ ] Keep it personal and authentic

## Pre-Launch Setup

### Hunter
- [ ] Identify a hunter with 1k+ followers (or self-hunt)
- [ ] Confirm hunter availability for launch day
- [ ] Share all assets with hunter 48 hours before launch

### Schedule
- [ ] Schedule launch for 00:01 PT (Product Hunt resets daily at midnight PT)
- [ ] Confirm launch date avoids major PH launches or holidays

### Supporters
- [ ] Notify waitlist 24 hours before launch with PH link
- [ ] Prepare tweet/post with direct PH link for supporters to share
- [ ] Draft DMs for close network asking for authentic reviews

## Day-of Checklist

- [ ] Verify listing is live and all assets display correctly
- [ ] Post maker comment immediately
- [ ] Share PH link on Twitter, LinkedIn, email
- [ ] Monitor and reply to every comment within 15 minutes
- [ ] Update listing description if needed based on feedback
- [ ] Track upvotes and ranking throughout the day

## Post-Launch

- [ ] Thank supporters publicly
- [ ] Add "Featured on Product Hunt" badge to website
- [ ] Compile feedback from PH comments into actionable items
- [ ] Follow up with users who left detailed reviews
