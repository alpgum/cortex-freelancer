## Installation Instructions

### Gmail
1. Go to Settings (gear icon) > See all settings > General tab
2. Scroll to "Signature" section
3. Click "Create new" and name it
4. Paste the HTML signature (switch to source/HTML mode if needed, or use a tool like htmlsig.com to paste)
5. Save changes

### Outlook (Desktop)
1. File > Options > Mail > Signatures
2. Create new signature
3. Paste the formatted signature into the editor
4. Set as default for new messages and replies

### Outlook (Web)
1. Settings (gear) > View all Outlook settings > Mail > Compose and reply
2. Paste into the signature editor
3. Save

### Apple Mail
1. Mail > Settings > Signatures
2. Select your account, click "+"
3. Uncheck "Always match my default message font"
4. Paste the formatted signature
5. Close settings

### Tips
- Always test by sending to yourself first
- Check rendering on mobile
- Some clients strip background colors -- the light versions are safest for broad compatibility
- The minimal variation (Variation 2) has the highest compatibility across all clients
