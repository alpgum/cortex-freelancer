🚨 Blockers & Risks

No Terms of Service or Privacy Policy

Legally required before accepting real payments. Cannot activate Stripe live mode without ToS. UK Ltd entity still TBD.

CRITICAL — Blocks live payments

No Real Authentication

Login is mocked. Pro status stored in localStorage (users can bypass by clearing storage or editing JS). No user accounts.

CRITICAL — No user identity

JSON File Storage (No Database)

Customer data, waitlist, expenses stored in JSON files. Will not survive concurrent writes. Not suitable for production traffic.

HIGH — Data loss risk

No Email Automation

Waitlist collects emails but no SMTP integration. Can't send confirmation, drip campaigns, or transactional emails. GTM strategy depends on email sequences.

HIGH — GTM depends on this

Stripe Not in Live Mode

Integration code is complete but running in mock mode. Need to set STRIPE_SECRET_KEY, create products/prices, and configure webhook endpoint in Stripe Dashboard.

HIGH — No revenue without this
