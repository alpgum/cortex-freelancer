# Project Manager Agent — KNOWLEDGE

## Freelance Project Lifecycle

Every successful freelance project follows the same arc: **Scoping → Agreement → Milestones → Delivery → Feedback**. Problems happen when steps get skipped.

**Scoping:** Before accepting any project, nail down: What exactly is being built? What's out of scope? What does "done" look like? What format does the deliverable take? Get this in writing — a brief message in the platform's chat is legally binding on most platforms.

**Agreement:** Confirm: total budget (or hourly rate + estimated hours), milestone breakdown, delivery timeline, number of revision rounds included, communication frequency. On Upwork, this maps to a contract with funded milestones. On Fiverr, this maps to order requirements + any extras.

**Milestones:** Break every project into 2-5 milestones. Each milestone should be a concrete deliverable that the client can review independently. Never put more than 40% of the total budget in the final milestone — frontload payment to reduce risk.

**Delivery:** Every delivery should include: the deliverable itself, a brief summary of what's included, any known limitations, and a clear next step ("Please review by [date]"). Clean handoffs build trust.

**Feedback:** After successful delivery, wait 24-48 hours (let them enjoy the work), then send a warm request for a review. Be specific: "If you're happy with the project, a brief review mentioning [specific aspect] would help me a lot."

## Milestone Structure Best Practices

**Good milestone breakdown for a typical web project ($3,000):**
1. Discovery + Wireframes — $600 (20%) — 3-5 days
2. Design Mockups — $750 (25%) — 5-7 days
3. Frontend Development — $750 (25%) — 7-10 days
4. Backend + Integration — $600 (20%) — 5-7 days
5. Testing + Launch — $300 (10%) — 3-5 days

**Rules of thumb:**
- First milestone should be small and fast — builds trust on both sides
- Final milestone should be the smallest — avoid holding large amounts hostage to "final approval"
- Each milestone should take no longer than 2 weeks — long gaps without deliverables erode client confidence
- Always include a "buffer" milestone for revisions if the project is complex

## Client Communication Cadence

**Daily:** Internal progress tracking (your task list, blockers, hours logged)
**2-3x per week:** Brief status message to client — what's done, what's next, any blockers
**Weekly:** Detailed status report (use the weekly-status template) for projects longer than 2 weeks
**Milestone completion:** Formal delivery message with review instructions
**Post-project:** Thank you + review request

**When to stay quiet:** Don't message when you have nothing new. "Just checking in" without content wastes the client's time and trains them to ignore your messages.

## Scope Creep Management

Scope creep is the #1 profitability killer for freelancers. Handle it with the **ACE method:**

1. **Acknowledge:** "That's a great idea, I can see how that would add value."
2. **Clarify impact:** "Adding this feature would take approximately X additional hours/days and affect the timeline by Y."
3. **Offer options:** "We can: (A) add it to this project for $X additional, (B) finish the current scope first and handle it as a follow-up project, or (C) swap it with [lower-priority feature] to keep the budget the same."

Never say "that wasn't in the scope" without offering a solution. Never do out-of-scope work for free — it sets a precedent.

## Time Estimation Frameworks

**The Buffer Rule:** Whatever your initial estimate is, add 30%. This accounts for communication overhead, revisions, and the unexpected. It's not padding — it's realism.

**Break it down:** Never estimate a project as one block. Break into sub-tasks, estimate each, then sum. A "3-week project" sounds reasonable until you list the 15 sub-tasks that each take 2-4 hours.

**Estimation by analogy:** "My last similar project took X hours." Adjust for: different tech stack (+20%), new client (extra communication, +15%), unclear requirements (+25%).

**Track actuals:** After every project, note estimated vs. actual time. After 10 projects, your estimates will be within 10% accuracy.

## Delivery Checklist by Project Type

**Web Development:** Source code (clean, commented), deployment instructions, admin credentials, README, any environment variables documented, browser testing results.

**Design:** Source files (Figma/PSD/AI), exported assets (PNG/SVG/PDF in all sizes), font list, color codes, usage guidelines if applicable.

**Content/Writing:** Final document (DOCX + Google Doc), SEO metadata (if applicable), source links for any statistics cited, image suggestions with alt text.

**Mobile App:** Source code, build instructions, test accounts, App Store/Play Store metadata, screenshots, privacy policy if needed.

## Difficult Client Handling

**Late Payments:** Follow up at 3 days (gentle reminder), 7 days (firmer, reference platform terms), 14 days (escalate through platform's dispute system). Never continue work on unfunded milestones.

**Changing Requirements:** Document every change request in writing. If verbal, summarize in chat: "Just to confirm, you'd like me to [change]. This will [impact]. I'll proceed unless you say otherwise."

**Ghost Clients:** If a client stops responding: Day 3 — check in ("Want to make sure you received the delivery"). Day 7 — follow up with deadline ("I'll close this milestone on [date] if I don't hear back"). Day 14 — formal notice through platform. On Upwork, you can request milestone release after 14 days of no response.

**Unreasonable Revision Loops:** After the agreed revision rounds, message: "I've completed the [X] revision rounds included in our agreement. I'm happy to continue refining — would you like me to submit a change order for additional revisions at [rate]?"

## Platform-Specific Knowledge

**Upwork Milestones/Escrow:** Client funds milestone before work begins. Freelancer submits work, client has 14 days to review. If no action, funds auto-release. Always ensure milestone is funded before starting work.

**Fiverr Order Management:** Orders have a delivery countdown. Late delivery hurts your ranking. Use the "extend delivery" feature BEFORE the deadline, not after. Revision requests reset the clock. Maximum 3 revisions on Standard, unlimited on Premium (if you set it that way).

**Both platforms:** Keep ALL communication on-platform. Off-platform communication isn't covered by dispute resolution. Never share personal contact info until trust is established.
