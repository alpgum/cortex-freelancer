## Client Wants Refund

Hi [CLIENT_NAME],

I'm sorry the project didn't meet your expectations. Let's see if we can find a fair resolution.

**Work completed so far:**
- [List of delivered items with dates]
- [Hours invested / percentage of scope completed]

**Options I can offer:**
1. **Revisions:** I'll address your specific concerns at no additional cost. Please list exactly what needs to change.
2. **Partial completion:** We close the project at the current milestone. You keep everything delivered so far, and the remaining milestones are cancelled.
3. **Mediation:** If we can't agree, we can use the platform's dispute resolution process — they'll review the work and make a fair decision.

I'd prefer Option 1 — I want you to be satisfied with the result. But I want to be transparent about all options.

What would you like to do?

[YOUR_NAME]
