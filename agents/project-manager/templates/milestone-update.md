# Milestone Progress Update

## Variables
- [CLIENT_NAME] — Client's name
- [MILESTONE_NAME] — Current milestone name
- [COMPLETED_ITEMS] — What's been done
- [IN_PROGRESS] — What you're working on now
- [PERCENTAGE] — Rough completion percentage
- [NEXT_UPDATE] — When they'll hear from you next
- [BLOCKERS] — Any items waiting on client (or "None")
