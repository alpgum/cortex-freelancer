# Payment Reminder

## Variables
- [CLIENT_NAME] — Client's name
- [PROJECT_NAME] — Project name
- [MILESTONE_NAME] — Milestone awaiting payment
- [AMOUNT] — Amount due
- [DAYS_OVERDUE] — Days since delivery/approval
- [DELIVERY_DATE] — When you delivered
