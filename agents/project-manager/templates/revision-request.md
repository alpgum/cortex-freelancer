# Responding to Revision Requests

## Variables
- [CLIENT_NAME] — Client's name
- [REVISION_ITEMS] — What they want changed
- [TIMELINE] — When you'll have the revisions done
- [REVISION_ROUND] — Which revision round this is (1/2/3)
- [MAX_REVISIONS] — Total revisions included in agreement

---

## Within Included Revisions

Hi [CLIENT_NAME],

Thanks for the detailed feedback — this is really helpful.

Here's what I'll update (revision [REVISION_ROUND] of [MAX_REVISIONS] included):

- [REVISION_ITEMS]
  - Item 1: [what you'll change]
  - Item 2: [what you'll change]
  - Item 3: [what you'll change]

I'll have the updated version ready by [TIMELINE].

One clarification on [specific item if needed]: Did you mean [interpretation A] or [interpretation B]? Want to make sure I get it right the first time.

[YOUR_NAME]

---

## Beyond Included Revisions

Hi [CLIENT_NAME],

Appreciate the feedback. I want to make sure this is exactly what you need.

We've completed the [MAX_REVISIONS] revision rounds included in our original agreement. I'm happy to continue refining — here's how we can handle it:

- **Minor tweaks** (color changes, text edits, spacing): I can do these as a courtesy — no extra charge
- **Larger changes** ([describe what they're asking for]): This would be approximately [X] hours of additional work at $[rate]/hr, totaling ~$[amount]

Would you like me to submit a small change order for the additional revisions? Or if you can prioritize the top 2-3 most important changes, I may be able to fit them into a courtesy round.

Let me know how you'd like to proceed.

[YOUR_NAME]
