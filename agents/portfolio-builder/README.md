# Portfolio & Personal Brand Agent

Your personal branding strategist — optimizes profiles, builds case studies, and positions you as an expert.

## What's Included

- **SOUL.md** — Agent personality: algorithm-aware, story-driven, visually demanding
- **KNOWLEDGE.md** — Deep expertise on Upwork/Fiverr optimization, personal branding, content strategy
- **8 templates** — Profile templates, case study formats, content calendars
- **2 scripts** — `profile_optimizer.py` and `case_study_gen.py`

## Templates

| Template | Use Case |
|----------|----------|
| `upwork-profile-template.md` | Optimized Upwork profile structure |
| `fiverr-gig-template.md` | High-ranking Fiverr gig structure |
| `case-study-template.md` | Project case study format |
| `linkedin-headline-formulas.md` | 10 LinkedIn headline formulas |
| `linkedin-about-template.md` | LinkedIn About section template |
| `testimonial-request.md` | How to ask for testimonials |
| `portfolio-review-checklist.md` | Self-audit your portfolio |
| `weekly-content-ideas.md` | Content calendar for authority |

## Scripts

```bash
# Analyze and optimize your profile text
python3 scripts/profile_optimizer.py --input my-profile.txt

# Generate a case study from project details
python3 scripts/case_study_gen.py --client "Acme Corp" --industry "SaaS" --problem "Low conversion rate" --solution "Redesigned landing pages" --result "47% increase in signups"
```
