# Deep Work Rules

## Your Deep Work Protocol

### Rule 1: Schedule It Like a Meeting
Deep work doesn't happen by accident. Block [HOURS — e.g., "9 AM - 12 PM"] on your calendar every [FREQUENCY — e.g., "weekday morning"]. Treat it as a non-negotiable appointment with your most important client: yourself.

### Rule 2: Define the Task Before You Start
Before entering a deep work block, write down exactly what you'll work on:
- **Project:** [PROJECT_NAME]
- **Task:** [SPECIFIC_TASK — "Build the API endpoint for user auth" not "Work on the project"]
- **Done when:** [COMPLETION CRITERIA — "Endpoint passes all 5 test cases"]

### Rule 3: Eliminate All Interruptions
- [ ] Phone on silent / Do Not Disturb mode
- [ ] Email client closed (not minimized — closed)
- [ ] Slack/Discord/Teams set to DND
- [ ] Browser tabs: only what you need for this task
- [ ] Physical space: door closed, headphones on, "Do Not Disturb" signal

### Rule 4: No Task Switching
If something "urgent" comes to mind during deep work:
1. Write it on a notepad (physical or a quick note file)
2. Return to your task immediately
3. Handle the note during your next break
4. 95% of "urgent" things can wait 2 hours

### Rule 5: Respect the Transition
- **Before deep work:** 5-minute ritual (close apps, review task, get water)
- **After deep work:** 10-minute cooldown (stretch, check messages, update task status)
- **Between meetings and deep work:** Minimum 15-minute buffer

### Rule 6: Protect It From Clients
Communicate your deep work hours to clients upfront:

> "I do my best focused work in the mornings, so I'm available for calls and messages from [TIME] onwards. If anything urgent comes up before then, I'll see it during my first check-in at [TIME]."

Most clients respect this — it signals professionalism, not unavailability.

Track weekly:

- Interruptions that broke a session: ___

**Goal:** Minimum [TARGET — e.g., "15"] hours of deep work per week.

---

## When Deep Work Gets Broken

If your deep work keeps getting interrupted, diagnose:
- **Client messages during DW hours?** → Set clearer expectations, batch responses
- **Self-interruption (checking email/social)?** → Use a website blocker
- **Household interruptions?** → Work from a different location, or use noise-canceling headphones as a signal
- **Meetings creeping into DW blocks?** → Move all meetings to afternoon; never schedule morning meetings
