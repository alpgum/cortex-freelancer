## Decision Framework

### Step 1: Does It Fit?
- [ ] New project hours ([X]) ≤ available capacity ([X])? → **YES / NO**
- [ ] If NO: Can any current project be paused, reduced, or finished before start date?
- [ ] Buffer check: Will you still have 15-20% unscheduled time? → **YES / NO**

### Step 2: Is It Worth It?
- [ ] Rate meets your minimum? (Your minimum: $[X]/hr) → **YES / NO**
- [ ] Revenue impact: $[WEEKLY_RATE] × [WEEKS] = **$[TOTAL]**
- [ ] Is this more profitable than your lowest-paying current project? → **YES / NO**
- [ ] Strategic value? (Portfolio piece, new niche, referral potential) → **YES / NO**

### Step 3: Risk Check
- [ ] Scope clearly defined? → **YES / NO**
- [ ] Client vetted? (Reviews, payment history, communication style) → **YES / NO**
- [ ] Timeline realistic? → **YES / NO**
- [ ] Any red flags? → **YES / NO**

### Step 4: Decision
- **GREEN (Take it):** Fits capacity, meets rate, low risk, clear scope
- **YELLOW (Negotiate):** Tight on capacity or rate — discuss timeline flexibility or higher rate
- **RED (Decline):** Over capacity, below rate floor, or multiple red flags
