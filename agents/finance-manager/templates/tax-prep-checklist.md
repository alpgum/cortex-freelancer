# Tax Season Preparation Checklist

*For freelancers in Egypt, Pakistan, Nigeria, and Turkey*

---

## General Preparation (All Countries)

### Income Documentation
- [ ] Download all payment platform statements (Cenoa, Payoneer, Wise, PayPal)
- [ ] Export Upwork earnings report (Reports → Transaction History → Export)
- [ ] Export Fiverr earnings report (Earnings → Revenue)
- [ ] Compile list of direct client payments with dates and amounts
- [ ] Calculate total gross income in USD
- [ ] Calculate total gross income in local currency (use actual conversion rates, not estimates)

### Expense Documentation
- [ ] Platform fees paid (Upwork service fee, Fiverr commission, Payoneer fees)
- [ ] Software subscriptions (hosting, tools, design software, IDE licenses)
- [ ] Hardware purchases (laptop, monitor, peripherals)
- [ ] Internet and phone bills (business portion)
- [ ] Coworking space or home office expenses
- [ ] Professional development (courses, books, certifications)
- [ ] Accounting/legal fees
- [ ] Bank and transfer fees

### Invoice Records
- [ ] All invoices issued (numbered sequentially)
- [ ] All invoices paid (match to bank deposits)
- [ ] Outstanding invoices (amounts still owed to you)
- [ ] Credit notes or refunds issued

## Country-Specific Checklists

### Egypt
- [ ] Check if income exceeds EGP 500,000 VAT threshold
- [ ] Prepare tax card (بطاقة ضريبية) if not already registered
- [ ] Calculate income tax using progressive rates
- [ ] File annual tax return at local tax office or online via eta.gov.eg
- [ ] Keep all records for 5 years (tax authority audit window)
- [ ] Consider engaging a local mohaseb (accountant) if earning above EGP 30K/month

### Pakistan
- [ ] Verify eligibility for IT freelancer tax exemption
- [ ] Ensure all income received through proper banking channels (required for exemption)
- [ ] Check PSEB registration status (Pakistan Software Export Board)
- [ ] File income tax return via FBR's IRIS portal
- [ ] Keep State Bank of Pakistan (SBP) compliant records for forex receipts
- [ ] Document foreign income sources (client contracts, platform reports)

### Nigeria
- [ ] Calculate total income against personal income tax thresholds
- [ ] Check if revenue exceeds NGN 25M VAT threshold
- [ ] Obtain TIN (Tax Identification Number) if not already registered
- [ ] File annual return with FIRS or state IRS
- [ ] Keep records of all foreign income and local conversions
- [ ] Document business expenses for deduction claims

### Turkey
- [ ] Verify serbest meslek or sahis sirketi registration
- [ ] Confirm SGK contributions are current (check via e-Devlet)
- [ ] Calculate gelir vergisi (income tax) using progressive rates
- [ ] Check KDV (VAT) exemption eligibility
- [ ] File quarterly geçici vergi beyannamesi (provisional tax returns)
- [ ] File annual gelir vergisi beyannamesi by March 31
- [ ] Keep all faturalar (invoices) for 5 years

## Pro Tips

1. **Keep a separate bank account** for freelance income — makes tax prep 10x easier
2. **Track expenses monthly**, not annually — you'll forget half your deductions otherwise
3. **Save 20-25% of gross income** for taxes throughout the year (adjust based on your country's rates)
4. **Get an accountant** — the cost ($100-300/year in most markets) pays for itself in deductions you'd miss
5. **Digital records are fine** — you don't need paper invoices, but do keep organized backups
